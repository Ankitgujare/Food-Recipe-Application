# Recipe Application

Welcome to the Recipe Application! This is a modern Android app built with Kotlin and Jetpack Compose that helps you discover, explore, and save your favorite recipes.

## 🍽️ What This App Does

The Recipe Application is designed to make cooking easier and more enjoyable. It provides a comprehensive platform where users can:
- Browse a wide variety of recipes
- View detailed recipe information including ingredients and instructions
- Bookmark recipes for quick access
- Discover new dishes based on cuisine, difficulty level, and dietary preferences
- Search for specific recipes by name

## 🌟 Features

### Current Features
- **Recipe Browsing**: Explore a diverse collection of recipes organized by categories
- **Detailed Recipe Views**: Get comprehensive information about each recipe including ingredients, instructions, cooking time, and nutritional information
- **Bookmark System**: Save your favorite recipes for easy access later
- **Recipe of the Week**: Highlight featured recipes on the home screen
- **Search Functionality**: Easily find specific recipes by name with real-time filtering
- **Category Filtering**: Filter recipes by meal type (Breakfast, Lunch, Dinner, etc.)
- **Responsive UI**: Beautiful, modern interface built with Jetpack Compose
- **Smooth Animations**: Enhanced user experience with subtle animations and transitions

### Technical Features
- Built with Kotlin and Jetpack Compose
- Modern Material Design 3 implementation
- Clean architecture with separation of concerns
- Responsive layout that works on different screen sizes
- MVVM pattern with ViewModel and StateFlow
- REST API integration with Retrofit
- Image loading with Coil

## 🚀 Getting Started

### Prerequisites
- Android Studio Ladybug or later
- Kotlin 1.9+
- Android SDK API 34 (Android 14) or later

### Installation
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/recipe-application.git
   ```
2. Open the project in Android Studio
3. Build and run the application

### Building the Project
1. Open the project in Android Studio
2. Select "Build" > "Make Project" or press `Ctrl+F9`
3. Run the app on an emulator or physical device

## 🔍 Search Functionality

The app includes a powerful search feature that allows users to quickly find recipes:

1. **Real-time Search**: As you type in the search bar, recipes are filtered instantly
2. **Case-insensitive Matching**: Search works regardless of letter casing
3. **Partial Matching**: Find recipes even with partial name matches
4. **Combined Filtering**: Search works in combination with category filters

To use the search functionality:
1. Open the app and navigate to the home screen
2. Tap on the search bar at the top
3. Type the name or keywords of the recipe you're looking for
4. Browse through the filtered results
